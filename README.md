# Simulador RV y RA
 
Simulador 3D hecho para la exposición de **Interacción Persona-Ordenador** sobre Realidad Virtual y Realidad Aumentada.
 
La misma aula se muestra de tres formas:
 
- **Mundo real:** el aula sin contenido digital.
- **Realidad aumentada (Microsoft HoloLens 2):** escaneo espacial de la sala y hologramas anclados a objetos reales. Con la vista del visor se ve el campo holográfico limitado (≈ 43° × 29°).
- **Realidad virtual (PICO 4 Ultra):** el aula se reemplaza por un mundo generado por ordenador, con teletransporte y vista estereoscópica.
**Controles:** teclas `1`, `2` y `3` para cambiar de modo, `V` para la vista del visor, y arrastrar para mirar alrededor.
 
Hecho con [three.js](https://threejs.org/) r128.
